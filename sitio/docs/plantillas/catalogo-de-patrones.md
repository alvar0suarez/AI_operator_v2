# Catálogo de patrones

> Artefacto 2 de 6 (`b2-m10-catalogo-de-patrones`). Los seis verbos, con **ejemplos
> de tu trabajo real escritos por ti**. Los ejemplos del curso no cuentan: si copias
> los míos, el catálogo no te sirve para nada.

---

## Los seis verbos

Para cada uno: dos ejemplos tuyos, uno donde el verbo brilla y otro donde lo has
visto fallar o crees que fallaría. **El segundo es el que enseña.**

## Mis cadenas

Las tareas que no son un verbo sino varios encadenados. Marca dónde pondrías el
punto de control humano.

| Tarea | Cadena | ¿Dónde miro yo? | ¿Por qué ahí? |
|---|---|---|---|
|  | extraer → clasificar → ... |  |  |
|  |  |  |  |

## Lo que no es ninguno de los seis

Tareas tuyas que **no** se delegan, con la razón. Las tres razones válidas: juicio con
consecuencias, responsabilidad legal, relación humana.

| Tarea | Razón | ¿Hay alguna parte que sí se pueda delegar? |
|---|---|---|
|  |  |  |
|  |  |  |

> La tercera columna importa. Casi nunca es todo o nada: puedes no delegar la decisión
> y sí delegar el borrador, o al revés.

## Rúbrica

| Nivel | |
|---|---|
| **No llegó** | Ejemplos genéricos o copiados del curso; verbos sin ejemplo; casillas de "dónde fallaría" en blanco. |
| **Llegó** | Los seis verbos con dos ejemplos propios cada uno, cruzados con el inventario del bloque 1, y al menos tres tareas en la tabla de "no se delega" con su razón. |
| **Llegó y encontró algo que no estaba previsto** | Lo anterior, y además una tarea que creía de un verbo y resulta ser de otro, o una cadena que había estado tratando como un solo paso. |

> **Un verbo sin ningún ejemplo tuyo casi nunca significa que no lo uses.** Significa
> que no lo has reconocido todavía. Vuelve al nodo de ese verbo antes de dejarlo en
> blanco.
